# NuVision

Portfolio website for NuVision — POS systems, QR menus, business websites, CV design and custom software.

A single static page (`index.html`) with screenshots in `assets/projects/`. No build step.

- **Kurdish (Badini):** fill in the `I18N.ku` strings in `index.html`; the language switch appears automatically.
- **Contact form:** set `FORM_ENDPOINT` in `index.html` to a Formspree URL; until then the form opens WhatsApp.
